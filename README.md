# Carte au Trésor

Axel LABARRE

## Dépendances

```sh
npm install
```

## Utilisation

- Compiler le projet

```sh
npm run build
```

- Lancer le projet en mode dev

```sh
npm run dev
```

- Lancer le projet en mode prod

```sh
npm run start
```

- Exécuter les tests en mode "watch"

```sh
npm run test
```

- Exécuter les tests sans mode "watch"

```sh
npm run jest
```

- Rapport de couverture

```sh
npm run test:coverage
```
